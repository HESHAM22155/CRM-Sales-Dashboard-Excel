# CRM-Sales-Dashboard-Excel
Excel CRM Sales Dashboard | DEPI Scholarship Project

This project was developed as part of the Digital Egypt Pioneers Initiative (DEPI) scholarship.
It focuses on building a comprehensive CRM Sales Dashboard using Microsoft Excel.

## Dashboard Insights
- Profit Analysis (Monthly trends)
- Opportunity Tracking (Total: 8,800 | Won: 4,238 | Lost: 2,473)
- Top 5 Managers & Sales Agents Leaderboard
- Regional & Quarterly Performance (Central, East, West | Q1–Q4)
- Win/Loss Ratio Analysis

## Tools & Skills
Excel, Pivot Tables, Slicers, Advanced Formulas, Dashboard Design, Data Storytelling
